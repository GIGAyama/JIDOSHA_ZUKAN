# じどう車ずかん

小学1年生 国語「**じどう車ずかんを つくろう**」（書くことの単元）のための、タブレットで使う調べ学習サイトです。

前の単元「じどう車くらべ」で学んだ **説明の順序**（しごと → その ために → つくり）を、そのまま
画面の操作としてたどれるようにしてあります。本を一人1冊用意できなくても、児童が各自で
「自分の1台」を調べ、そのまま書く活動に入れることをねらいとしています。

公開URL（Pages を有効にした場合）: <https://gigayama.github.io/JIDOSHA_ZUKAN/>

## つかいかた

### 児童
1. 一覧から調べたい車を選ぶ
2. 「こたえを 見る →」を押して、①とい → ②しごと → ③つくり の順に読む
3. 「つくり」の文を押して、絵のどこのことか確かめる
4. 「🔬 ものすごく 大きく 見る」で、車のすみずみまで観察する
5. 調べたことを、①とい → ②しごと → ③つくり の順にノートへ書く

### 先生
- 大型提示装置に映して全体で読む場合も、同じ順に開けば説明の順序をたどれます。
- 「大きさくらべ」は、書く材料（大きさ・長さ）を見つける手がかりになります。
- 「ものすごい かんさつ」は、書く材料を**自分で見つける**時間に向いています。
  ①②③を読む前に開くと予想活動に、読んだあとに開くと確かめ活動になります。

## ものすごい かんさつ（`#/kansatsu/<id>`）

暗い部屋で1台にライトを当てたような全画面の観察モードです。イラストがベクター（SVG）なので、
**どれだけ寄っても線がぼやけません**。

| そうさ | できること |
| --- | --- |
| ゆびでドラッグ／ピンチ | 動かす・大きくする（マウスはドラッグとホイール、ダブルクリックでも寄れる） |
| 右下のバー | ＋ − スライダー ⟲（もとにもどす）。倍率も出る |
| ◯印（①②③…） | その部分へカメラが飛び、まわりが暗くなってそこだけ光る。名前と説明が出る |
| 下のリスト | 全部の部分を切り出した小さな絵で一覧。押すとその部分へ飛ぶ |
| キーボード | `Esc` で閉じる（部分を選んでいるときは、まず選択を解除） |

- ◯印は `car-art.js` の `data-part` から**自動で作られます**。イラストに部品を足せば、印も増えます。
- 見た部分には ✓ が付き、端末に保存されます。全部見つけると「ぜんぶ みつけた！」が出ます。
- その車の `tsukuri` に同じ `part` があるときは、教科書と同じ**「③ つくり」の文**も並びます。
  辞書の説明（どの車にも共通）と、その車の説明（本文）が1か所でつながります。
- この画面では `photo` を設定していても**イラストを使います**（写真では部分を光らせられないため）。

### 部分の名前と説明を足す・直す（`parts-data.js`）

```js
window.partInfo = {
  tire: {
    name: 'タイヤ',
    text: 'ゴムで できた わです。まわって 車を すすめ、……'
  }
};
```

`car-art.js` の `data-part` と同じキーにします。書き方のきまり（分かち書き・全部の漢字にルビ）は
`cars-data.js` と同じで、`selftest.html` が次を自動で確かめます。

- 絵にある `data-part` が全部 `partInfo` にそろっているか
- `partInfo` に使われていないキーが残っていないか
- 説明の漢字にルビの付け忘れがないか

## じどう車を 追加・変更する

### 1. 説明文（`cars-data.js`）

```js
{
  id: 'truck',                  // 半角英字。URL（#/car/truck）になる
  name: 'トラック',              // 画面に出る名前（漢字には <ruby> を付ける）
  kana: 'トラック',              // 読み上げソフト用のよみ
  category: 'hakobu',           // hakobu / tsukuru / mamoru / kurashi / sodateru / basho
  art: 'truck',                 // car-art.js のキー
  photo: null,                  // 'assets/truck.webp' を入れると写真が優先される
  shigoto: '……する しごとを して います。',
  tsukuri: [
    { part: 'nidai', label: 'にだい', text: 'その ために、……' },
    { part: 'tire',  label: 'タイヤ', text: '……ように、……' }
  ],
  hakken: 'もっと しりたい 人へ の 一言。'
}
```

**書くときのきまり**

- `shigoto` は必ず `〜しごとを して います。` で終える
- `tsukuri[0].text` は必ず `その ために、` で始める
- `tsukuri[1].text` には必ず `〜ように、` を入れる（そのつくりの「わけ」を書く）
- **その車にしか当てはまらないことを1つ入れる**——「うしろの とびらが 大きく ひらきます」のように
  どの車にも書ける文にしない。かず（何本・何だん）、たとえ（つりざお・まほうびん）、
  その車だけのしくみ（にだいが かたむく・かごが まっすぐ たもたれる）のどれかを入れる
- 分かち書き（ことばの間を半角スペースであける）
- **漢字にはすべて `<ruby>漢字<rt>よみ</rt></ruby>` を付ける**（読み上げもこの読みを使います）
- `part` は `car-art.js` の `data-part` と同じ名前にする → その部分が光る

### 2. イラスト（`car-art.js`）

`ART.〇〇 = { label, w, h, draw(L) }` を足します。

- 地面は `y = 200`、**1メートル ＝ 28たんい**（全車共通の縮尺）
- `w`・`h` は実際に描いた大きさ（たんい）。ここから「ながさ やく◯メートル」を計算します
- 「大きさくらべ」の枠に収まるのは `w ≦ 440`（約15.7メートル）・`h ≦ 180`（約6.4メートル）まで
- `rect() / circ() / poly() / line() / path() / wheel() / glass()` などの部品ヘルパーを使います
- 説明したい部分には `{ part: 'nidai' }` のように `part` を渡す

### 3. たしかめる

`selftest.html` をブラウザで開くと、次をまとめて確認できます。

- 全60台が①→②→③の順にしか開かないか
- `tsukuri[].part` に対応する部分が絵の中にあり、実際に光るか
- ふきだしが絵からはみ出さないか
- 読み上げテキストに漢字が残っていないか
- 全60台で◯印の数が絵の部分の数と合い、画面の中に収まっているか
- ◯印を押すと光る・説明が出る・✓が付いて保存されるか
- `parts-data.js` が絵の `data-part` を全部カバーし、ルビの付け忘れがないか

`ALL PASS` と出れば大丈夫です。

3Dモデルのほうは `selftest3d.html` が別に確かめます（つくりの part が3Dにあるか、
実際に光るか、大きさがおかしくないか、◯印が画面に収まるか、など）。

## 3Dで まわして 見る

**収録している60台すべて**が、ブラウザの中で組み立てた3Dモデルになっています。
6つのしごとのどれを選んでも、指で回して見られます。

| しごと | 3D |
| --- | --- |
| はこぶ | 14 / 14 |
| つくる・なおす | 13 / 13 |
| たすける・まもる | 11 / 11 |
| くらしを ささえる | 10 / 10 |
| そだてる・とる | 6 / 6 |
| くうこう・みなと・えき | 6 / 6 |

- 詳細ページの絵がそのまま3Dになります。「🖼️ イラストで 見る」でいつでも戻れます
- 「③ つくり」の文を押すと、**3Dのその部分だけが光ります**（写真では使えなかった機能が、3Dでは使えます）
- 「ものすごい かんさつ」も3D版になります。◯印は車を回してもついてきて、うら側に行くと消えます
- **▶ ボタン**で、にだいがかたむく・はしごがのびる・としょかん車のかべがひらく などを実際に動かせます
- WebGLが使えない端末では、**これまでどおりイラスト**が出ます（3Dは動的読みこみなので、失敗してもずかんは動きます）

作りかた・じどう車の足しかた・組みこみの中身は [`README-3D.md`](README-3D.md) を見てください。
three.js を `vendor/` に同梱しているので、**ビルドは不要のまま**です。

## 写真に 差しかえる

イラストのかわりに写真を使いたいときは、`assets/` に画像を置き、`cars-data.js` の
`photo` にパスを書きます（例: `photo: 'assets/truck.webp'`）。
`photo` が入っている車だけ写真になり、`null` のままの車はイラストのままです。

くわしくは [`assets/README.md`](assets/README.md) を見てください。

> 写真にすると、部位ハイライト（絵の一部を光らせる機能）は使えません。
> 光らせたい部分がある車はイラストのままにしておくのがおすすめです。
> なお「ものすごい かんさつ」は、`photo` を設定していても常にイラストを使います。

## 動作について

- 読み上げは端末の音声合成（Web Speech API）を使います。日本語の音声が入っていない端末では
  音が出ないことがあります。
- ★と、ものすごい かんさつの ✓ は、その端末の `localStorage` に保存されます。端末をまたいでは
  共有されません。保存が禁止されている端末では印が残らないだけで、それ以外の機能はそのまま使えます。
- 文字は Google Fonts（BIZ UDPGothic / Kosugi Maru）を使いますが、学校のネットワークで
  読み込めなくても、端末の丸ゴシック系フォントで表示されます。

## 素材について

イラストはこのリポジトリ内で描いた SVG です。3Dモデルも、外部のモデルデータを使わず
`car3d.js` の中で箱や円柱から組み立てています（`vendor/three.module.min.js` は
three.js — MIT ライセンス）。説明の文章は、教科書と同じ文型・同じ順序に
そろえて新しく書き起こしたものです（教科書本文の転載はしていません）。
