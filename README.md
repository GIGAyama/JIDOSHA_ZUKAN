# じどう車ずかん

小学1年生 国語「**じどう車ずかんを つくろう**」（書くことの単元）のための、タブレットで使う調べ学習サイトです。

前の単元「じどう車くらべ」で学んだ **説明の順序**（しごと → その ために → つくり）を、そのまま
画面の操作としてたどれるようにしてあります。本を一人1冊用意できなくても、児童が各自で
「自分の1台」を調べ、そのまま書く活動に入れることをねらいとしています。

入り口は2つあります。

| 入り口 | URL | つかう時間 |
| --- | --- | --- |
| **📖 ずかん**（①とい → ②しごと → ③つくり） | `/#/` | 「じどう車くらべ」のふり返り・説明の順序の確かめ |
| **📚 じどう車の 本**（図鑑のように読んで、材料を自分で見つける） | `/#/hon` | 「じどう車ずかんを つくろう」第2〜4時の材料集め |

公開URL（Pages を有効にした場合）: <https://jidosha-zukan.giga-school.com/>

## できること

| 画面 | 内容 |
| --- | --- |
| **一覧** | 60台のじどう車。「はこぶ／つくる・なおす／たすける・まもる／くらしを ささえる／そだてる・とる／くうこう・みなと・えき」の6つのしごとで絞り込み |
| **詳細（ずかんのページ）** | ①とい → ②しごと → ③つくり の順に**しか**開かない。先に答えが見えないので、予想してから読める |

| **★ えらんだ 車** | 気になった車に印をつけて、あとから一覧で絞り込める |
| **大きさくらべ** | 全60台を**同じ縮尺**で並べる。となりに立っている1年生（約1.2m）と比べられる |
| **ものすごい かんさつ** | 全画面の観察モード。**最大14倍まで寄っても輪郭がぼやけない**（SVG）。部分に付いた◯印を押すとカメラがそこへ飛び、まわりが暗くなってその部分だけが光る |

| **▶ うごかす** | にだいがかたむく／はしごがのびる／バスのとびらがひらく など、「その ために、〜」の文がそのまま目の前で起こる |
| **📚 じどう車の 本** | 60台それぞれに、子ども向け図鑑のような1ページ（見出し3〜6・文11〜18・「かずで 見る」）。**教科書の型では書いていない**ので、どれが しごとで どれが つくりかを児童が自分で見分ける |
| **🖍️ ペンで 線を ひく** | しごとの文に**あお**、つくりの文に**みどり**の線。教科書に線を引いたのと同じことを画面でする |
| **📝 メモ** | 線を引いた文が しごと／つくり に分かれて集まり、「〇〇は、〜しごとを して います。その ために、〜。」の形といっしょに見られる |

### 3つの 見せかたの やくわり

同じ1台に、写真・イラスト・3Dの3つがあります。それぞれ役割が違います。

| 見せかた | やくわり | どこで出るか |
| --- | --- | --- |
| **📷 しゃしん** | ほんものの すがたを 見る | 一覧のカード／詳細ページ（3Dを止めたとき） |
| **🧊 3D** | まわして つくりを たしかめる | 詳細ページ（はじめから）／ものすごい かんさつ |
| **🖼️ イラスト** | ぶぶんを 光らせて 見る | 「つくり」の文をタップしたとき／大きさくらべ |

写真の車で「つくり」の文をタップすると、そのあいだだけイラストに入れかわって該当部分が光り、
もう一度タップすると写真に戻ります。写真には目印（`data-part`）が付けられないためです。

## つかいかた

### 児童
1. 一覧から調べたい車を選ぶ
2. 「こたえを 見る →」を押して、①とい → ②しごと → ③つくり の順に読む
3. 「つくり」の文を押して、絵のどこのことか確かめる
4. 「🔬 ものすごく 大きく 見る」で、車のすみずみまで観察する
5. 調べたことを、①とい → ②しごと → ③つくり の順にノートへ書く

### 児童（じどう車の 本 `#/hon`）
1. もくじから書きたい車を選び、本のページをさいごまで読む
2. 下の「しごと」のペンを持って、しごとのことが書いてある文を押す（あおい線が引ける）
3. 「つくり」のペンに持ちかえて、つくりのことが書いてある文を押す（みどりの線）
4. 「📝 メモ」を開くと、線を引いた文が集まっている。それを見て、ノートやカードに書く

### 先生
- **「じどう車ずかんを つくろう」の材料集めでは `https://jidosha-zukan.giga-school.com/#/hon` を配ってください。**
  カードを押すと本のページが開きます（①②③の答えのページを先に見ずに済みます）。
- 本のページは、しごと・つくり・その他（大きさ・はたらく人・まめちしき）がまざった、
  ふつうの図鑑のような書き方です。**「その ために」「〜しごとを して います」は本文に出てきません。**
  どの文を選び、どうつなぐかを児童が考えるためです。アプリは「その線は合っている」とは言いません。
- 本文はすべて、消防・警察・自治体・メーカーなどの公式資料で調べ、別の担当がもう一度調べ直して
  確かめています。ページの下の「しらべた ところ（せんせい・おうちの かたへ）」に出典があります。
  数は「やく」「くらい」の目安で、同じ種類の車でも大きさや作りは車ごとにちがいます。
- 線は端末に保存されるので、次の時間に続きから使えます。メモの「ぜんぶ けす」は2回押すと消えます。
- 大型提示装置に映して全体で読む場合も、同じ順に開けば説明の順序をたどれます。
- 「大きさくらべ」は、書く材料（大きさ・長さ）を見つける手がかりになります。
- 「ものすごい かんさつ」は、書く材料を**自分で見つける**時間に向いています。
  ①②③を読む前に開くと予想活動に、読んだあとに開くと確かめ活動になります。

## ものすごい かんさつ（`#/kansatsu/<id>`）

暗い部屋で1台にライトを当てたような全画面の観察モードです。イラストがベクター（SVG）なので、
**どれだけ寄っても線がぼやけません**。

| そうさ | できること |
| --- | --- |
| ゆびでドラッグ／ピンチ | 動かす・大きくする（マウスはドラッグとホイール、ダブルクリックでも寄れる） |
| 右下のバー | ＋ − スライダー ⟲（もとにもどす）。倍率も出る |
| ◯印（①②③…） | その部分へカメラが飛び、まわりが暗くなってそこだけ光る。名前と説明が出る |
| 下のリスト | 全部の部分を切り出した小さな絵で一覧。押すとその部分へ飛ぶ |
| キーボード | `Esc` で閉じる（部分を選んでいるときは、まず選択を解除） |

- ◯印は `car-art.js` の `data-part` から**自動で作られます**。イラストに部品を足せば、印も増えます。
- 見た部分には ✓ が付き、端末に保存されます。上のバーに「見た ぶぶん ◯こ」と出ます。
  「全部見つける」ことをゴールにはしていません。この単元のねらいは、書く材料を1つ2つ選ぶことなので、
  数は記録として静かに出すだけにしてあります（部品の数は3Dとイラストで異なります）。
- その車の `tsukuri` に同じ `part` があるときは、教科書と同じ**「③ つくり」の文**も並びます。
  辞書の説明（どの車にも共通）と、その車の説明（本文）が1か所でつながります。
- この画面では `photo` を設定していても**イラストを使います**（写真では部分を光らせられないため）。

### 部分の名前と説明を足す・直す（`parts-data.js`）

```js
window.partInfo = {
  tire: {
    name: 'タイヤ',
    text: 'ゴムで できた わです。まわって 車を すすめ、……'
  }
};
```

`car-art.js` の `data-part` と同じキーにします。書き方のきまり（分かち書き・全部の漢字にルビ）は
`cars-data.js` と同じで、`selftest.html` が次を自動で確かめます。

- 絵にある `data-part` が全部 `partInfo` にそろっているか
- `partInfo` に使われていないキーが残っていないか
- 説明の漢字にルビの付け忘れがないか

## じどう車を 追加・変更する

### 1. 説明文（`cars-data.js`）

```js
{
  id: 'truck',                  // 半角英字。URL（#/car/truck）になる
  name: 'トラック',              // 画面に出る名前（漢字には <ruby> を付ける）
  kana: 'トラック',              // 読み上げソフト用のよみ
  category: 'hakobu',           // hakobu / tsukuru / mamoru / kurashi / sodateru / basho
  art: 'truck',                 // car-art.js のキー
  photo: null,                  // 'assets/truck.webp' を入れると写真が優先される
  shigoto: '……する しごとを して います。',
  tsukuri: [
    { part: 'nidai', label: 'にだい', text: 'その ために、……' },
    { part: 'tire',  label: 'タイヤ', text: '……ように、……' }
  ],
  hakken: 'もっと しりたい 人へ の 一言。'
}
```

**書くときのきまり**

- `shigoto` は必ず `〜しごとを して います。` で終える
- `tsukuri[0].text` は必ず `その ために、` で始める
- `tsukuri[1].text` には必ず `〜ように、` を入れる（そのつくりの「わけ」を書く）
- **その車にしか当てはまらないことを1つ入れる**——「うしろの とびらが 大きく ひらきます」のように
  どの車にも書ける文にしない。かず（何本・何だん）、たとえ（つりざお・まほうびん）、
  その車だけのしくみ（にだいが かたむく・かごが まっすぐ たもたれる）のどれかを入れる
- 分かち書き（ことばの間を半角スペースであける）
- **漢字にはすべて `<ruby>漢字<rt>よみ</rt></ruby>` を付ける**（読み上げもこの読みを使います）
- `part` は `car-art.js` の `data-part` と同じ名前にする → その部分が光る

### 2. イラスト（`car-art.js`）

`ART.〇〇 = { label, w, h, draw(L) }` を足します。

- 地面は `y = 200`、**1メートル ＝ 28たんい**（全車共通の縮尺）
- `w`・`h` は実際に描いた大きさ（たんい）。ここから「ながさ やく◯メートル」を計算します
- 「大きさくらべ」の枠に収まるのは `w ≦ 440`（約15.7メートル）・`h ≦ 180`（約6.4メートル）まで
- `rect() / circ() / poly() / line() / path() / wheel() / glass()` などの部品ヘルパーを使います
- 説明したい部分には `{ part: 'nidai' }` のように `part` を渡す

### 3. たしかめる

`selftest.html` をブラウザで開くと、次をまとめて確認できます。

- 全60台が①→②→③の順にしか開かないか
- `tsukuri[].part` に対応する部分が絵の中にあり、実際に光るか
- ふきだしが絵からはみ出さないか
- 読み上げテキストに漢字が残っていないか
- 全60台で◯印の数が絵の部分の数と合い、画面の中に収まっているか
- ◯印を押すと光る・説明が出る・✓が付いて保存されるか
- `parts-data.js` が絵の `data-part` を全部カバーし、ルビの付け忘れがないか
- 全60台に本のページがあり、文・見出し・「かずで 見る」の数がデータと合うか
- 「👀 ここを 見て！」を押すと、全60台で絵のその部分が光り、ふきだしが絵の中に出るか
- ペンで線が引け、同じペンでもう一度押すと消え、メモに集まり、保存されるか

`ALL PASS` と出れば大丈夫です。

3Dモデルのほうは `selftest3d.html` が別に確かめます（つくりの part が3Dにあるか、
実際に光るか、大きさがおかしくないか、◯印が画面に収まるか、など）。

## じどう車の 本を 直す・足す（`hon-data.js`）

```js
window.honData = {
  ladder: {
    catch: '高い ところの 人を たすける、のびる はしごの 車',   // 名前の 下に 出る ひとこと
    pages: [
      { h: 'ぐんぐん のびる はしご', s: [                      // 見出しと 文
        { k: 't', part: 'ladder', t: 'はしご車の はしごは、……' }
      ] }
    ],
    kazu: [ { l: 'はしごの ながさ', v: '30〜40メートルくらい' } ],  // かずで 見る
    src:  [ { n: '○○消防局「はしご車」', u: 'https://…' } ]     // しらべた ところ
  }
};
```

**書くときのきまり**（`node tools/check-hon.mjs` が機械で見ます。CI でも走ります）

- **教科書の型にしない。** 「その ために」「しごとを して います」は書かない
- `k` は しごと＝`s`（2つ以上）／つくり＝`t`（5つ以上）／その他＝`o`（1つ以上）。全部で11〜18文。
  **画面には出ません**（材料が足りているかの検査だけに使う）
- 1文だけメモに写されても意味が通るように、主語を入れる（「これは」「その」で始めない）
- 分かち書き。漢字にはすべて `<ruby>`。数字は半角の算用数字（`<ruby>4本<rt>よんほん</rt></ruby>`）
- `part` は `car-art.js` の `data-part` と同じ名前。「👀 ここを 見て！」のボタンになり、押すと絵のその部分が光る（2種類以上）
- 事実は公式資料で確かめ、`src` に2つ以上書く。数には「やく」「くらい」を付ける。会社名・商品名・地名は書かない

⚠️ **文を1文字でも書きかえると、その文に児童が引いた線は消えます**（線は文の文字から作った鍵で保存しているため。
ちがう文に線が移ることはありません）。授業で使っている期間の書きかえは、なるべく避けてください。

## 3Dで まわして 見る

**収録している60台すべて**が、ブラウザの中で組み立てた3Dモデルになっています。
6つのしごとのどれを選んでも、指で回して見られます。

| しごと | 3D |
| --- | --- |
| はこぶ | 14 / 14 |
| つくる・なおす | 13 / 13 |
| たすける・まもる | 11 / 11 |
| くらしを ささえる | 10 / 10 |
| そだてる・とる | 6 / 6 |
| くうこう・みなと・えき | 6 / 6 |

- 詳細ページの絵がそのまま3Dになります。「📷 しゃしんで 見る」でいつでも戻れます
  （写真のない車では「🖼️ イラストで 見る」と出ます）
- 「③ つくり」の文を押すと、**3Dのその部分だけが光ります**（写真では使えなかった機能が、3Dでは使えます）
- 「ものすごい かんさつ」も3D版になります。◯印は車を回してもついてきて、うら側に行くと消えます
- **▶ ボタン**で、にだいがかたむく・はしごがのびる・としょかん車のかべがひらく などを実際に動かせます
- WebGLが使えない端末では、**これまでどおりイラスト**が出ます（3Dは動的読みこみなので、失敗してもずかんは動きます）

作りかた・じどう車の足しかた・組みこみの中身は [`README-3D.md`](README-3D.md) を見てください。
three.js を `vendor/` に同梱しているので、**ビルドは不要のまま**です。

## 写真に 差しかえる

イラストのかわりに写真を使いたいときは、`assets/` に画像を置き、`cars-data.js` の
`photo` にパスを書きます（例: `photo: 'assets/truck.webp'`）。
`photo` が入っている車だけ写真になり、`null` のままの車はイラストのままです。

くわしくは [`assets/README.md`](assets/README.md) を見てください。

> 写真にすると、部位ハイライト（絵の一部を光らせる機能）は使えません。

## 動作について

- 読み上げは端末の音声合成（Web Speech API）を使います。日本語の音声が入っていない端末では
  音が出ないことがあります。
- ★と、ものすごい かんさつの ✓、じどう車の本で引いた線は、その端末の `localStorage` に保存されます
  （線は `jz.hon.<車のid>`。文字や名前などは保存しません）。端末をまたいでは共有されません。
  保存が禁止されている端末では印が残らないだけで、それ以外の機能はそのまま使えます。
- 文字は Google Fonts（BIZ UDPGothic / Kosugi Maru）を使いますが、学校のネットワークで
  読み込めなくても、端末の丸ゴシック系フォントで表示されます。

## 素材について

イラストはこのリポジトリ内で描いた SVG です。3Dモデルも、外部のモデルデータを使わず
`car3d.js` の中で箱や円柱から組み立てています（`vendor/three.module.min.js` は
three.js — MIT ライセンス）。説明の文章は、教科書と同じ文型・同じ順序に
そろえて新しく書き起こしたものです（教科書本文の転載はしていません）。

「じどう車の 本」（`hon-data.js`）の文も、教科書や市販の図鑑の文を写さず、公的な資料
（消防・警察・自治体・省庁）、メーカーの製品資料、業界団体の資料などで調べた事実から
新しく書いています。1台ずつ、書いた担当とは別の担当がウェブの出典で1文ずつ確かめ直し、
確かめられなかった文は消すか「〜ものも あります」に弱めました。出典は各ページの
「しらべた ところ」と `hon-data.js` の `src` にあります。

その確かめ直しの途中で、①②③のページ（`cars-data.js`）の説明にも事実とちがう所が
見つかったので、出典で確かめられたものを直しました（2026-11-07。パトカーの赤色灯、
コンバインがためるのは「もみ」、田植え機は苗を3〜4本ずつ植える、救急車には赤十字を
付けない、など）。

### まだ のこって いる こと

- **出典のリンクは、このリポジトリの作業環境からは開けないものが多く、検索結果の要約で
  中身を確かめています。** 授業で使う前に、気になるページの「しらべた ところ」を開いて
  確かめてください。リンク切れや内容の変わったものがあれば、その文を直します。
- すいどうこうじ車の絵と3Dは、うでの先がバケット（土をほる形）になっています。
  調べた資料では、水道工事で土をほるのは別の重機と手作業で、車のうではクレーン（荷の積みおろし）
  でした。文はクレーンの説明に直してありますが、絵はまだ直していません。
- ガスこうじ車の絵のランプは黄色（工事中の作業灯）です。ガスもれに駆けつける車は
  赤色灯とサイレンの緊急自動車なので、本のページではランプの色を書いていません。
