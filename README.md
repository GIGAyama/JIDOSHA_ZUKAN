# じどう車ずかん

小学1年生 国語「**じどう車くらべ**」「**じどう車ずかんを つくろう**」で、図書室の図鑑のかわりに読む、
タブレット用の **はたらく じどう車の図鑑** です。60台のじどう車を、写真・見出しのついた説明・
「かずで 見る」・ぶぶんの名まえ といっしょに、本物の図鑑のようにのせています。

**この図鑑は「こたえ」を出しません。** 説明の文は教科書の型（「〜しごとを して います。その ために、〜」）
では書いておらず、「しごと」「つくり」というラベルや色わけもありません。子どもは図鑑を読んで、
えらんだ車のしごとと、そのしごとに合うつくりを自分で見つけ、ワークシートやノートに自分のことばで書きます。

公開URL: <https://jidosha-zukan.giga-school.com/>

> **2026-11-08 に作り直しました。** それまであった「①とい → ②しごと → ③つくり」の答えのページ
> （教科書の型の文で60台ぶん）と、文に線を引いてメモに集め「その ために」の型にならべる機能は、なくしました。
> アプリを操作して書き写すだけで「じどう車しょうかいカード」が仕上がってしまうためです。
> くわしくは下の「[作り直した わけ](#作り直した-わけ2026-11-08)」。

## 授業での つかいかた（先生へ）

指導書の流れ（「じどう車くらべ」全7時／「じどう車ずかんを つくろう」全5時）に合わせた例です。

| 時 | 図鑑の つかいかた |
| --- | --- |
| じどう車くらべ 第1時 | もくじを大型提示装置に映して、知っている車・見たことのある車を出し合う |
| じどう車くらべ 第7時 | 教科書p.34の「はしご車」には教材文がないので、図鑑の **はしご車（30ページ）** を読み、しごととつくりをノートに書く |
| じどう車ずかんを つくろう 第1時 | 「ずかんの 見かた」を映して、どこに何が書いてあるか（見出し・写真・かずで見る）を確かめる。紹介する車をえらんで 🔖 しおりをはさむ |
| 第2時 | えらんだ車のページを読み、しごとが書いてあるところを見つけて、ワークシートに短く書く |
| 第3時 | つくりが書いてあるところを見つけて書き、しごとに合うつくりをえらぶ |
| 第4〜5時 | 「じどう車しょうかいカード」を書く・読み合う（図鑑は見返すときに使う） |

- **「その ために」でつなぐのは子どもです。** 図鑑の文には、しごと・つくり・それ以外（大きさ、はたらく人、
  まめちしき）がまざっています。どの文をえらび、どうつなぐかを考えさせてください。
  アプリは「この文はつくりです」とは言いません。
- 「ぶぶんの名まえ」には、その車ならではの部分のほかに、タイヤ・まど・うんてんせきのような
  **どの車にもある部分** もならびます。「タイヤが ついて いる」ではなく、しごとに合うつくりをえらぶ手がかりにしてください。
- 本や図鑑によって書き方がちがうことも、図鑑を読む学習の一部です。この図鑑は、見出しを見れば
  何が書いてあるか分かるように作ってあります（見出しには「しごと」「つくり」という言葉を使っていません）。
- 読むのがむずかしい子は、見出しの横の「🔊 よむ」で聞けます（ふりがなの読みで読み上げます）。
- 文はすべて消防・警察・自治体・メーカーなどの公式資料で調べ、別の担当がもう一度確かめています。
  ページのいちばん下の「おとなの かたへ」に資料のリンクがあります。数は「やく」「くらい」の目安です。
- しおりはその端末に保存されるので、次の時間はもくじの「🔖 しおり」からすぐ開けます。

## 作り直した わけ（2026-11-08）

それまでのアプリは、支援をいちばんにした作りでした。

- 入り口の「ずかん」は、①とい →「こたえを 見る →」→ ②しごと →「その ために…」→ ③つくり の順にしか開かず、
  ②③には**教科書と同じ型の文**（「〜しごとを して います。」「その ために、〜」「〜ように、〜」）が
  60台ぶん用意されていました。もくじの「がくしゅうの ポイント」には
  「この じゅんばんで かくと、じぶんの『じどう車ずかん』の 文に なります」と書いてありました。
- 「じどう車の 本」も、しごとの文に青、つくりの文に緑の線を引くと「📝 メモ」に集まり、
  「〇〇は、□ しごとを して います。その ために、□。」の型といっしょに出る作りでした。
  「👀 ここを 見て！」のボタンには、本文でつくりとして書かれている部分だけがならんでいました。
- 「ものすごい かんさつ」でも、部分を押すと「③ つくり」の文が出て、その部分が①②として先にならんでいました。

2学期の終わりの1年生は、もう自分で読んで書く力がついています。これでは、アプリを操作して
写すだけでカードが仕上がり、指導書の言う「『しごと』と『つくり』を分けて情報収集し、
そこからどれを選んで文章にしていったのか」という過程が子どもの中に残りません。
そこで、図書室の図鑑をそのまま置きかえられる **ふつうの図鑑** にしました。

| まえ | いま |
| --- | --- |
| ①②③の答えのページ（`#/car/<id>`）と、教科書の型の文（`cars-data.js` の `shigoto` / `tsukuri` / `hakken`） | なくした。`#/car/<id>` は図鑑のページになった。型の文はデータからも消した（git の履歴には残っている） |
| 本のペン（しごと＝青・つくり＝緑）・メモ・カードの型 | なくした。端末に残っていた線（`jz.hon.*`）は、ひらいたときに1回だけ片づける |
| 「👀 ここを 見て！」（本文のつくりの部分だけ） | 「ぶぶんの名まえ」（絵にある部分ぜんぶ。どの車にもある部分もまざる） |
| かんさつの「③ つくり」の文と、その部分を先にならべる順番 | 部分の名まえと、どの車にもあてはまる説明だけ。ならびは絵の左から |
| ★ えらんだ 車 | 🔖 しおり（同じ保存場所 `jz.stars` を使うので、つけた印はそのまま残る） |
| 大きなヘッダーの手順（①しごと → ②つくり、ペンの使いかた）と「がくしゅうの ポイント」 | 図鑑の表紙ともくじ。手順の説明は出さない |
| 写真の出典・変えたところを写真の下に大きく、資料も本文のすぐ下に | 写真の下には撮影者とライセンスだけを小さく。のこりは「おとなの かたへ」にとじて入れた |
| — | さくいん・ずかんの見かた・ページばんごう・1年生とくらべた大きさ を足した |

## くわしく 見る（`#/kansatsu/<id>`）

暗い部屋で1台にライトを当てたような全画面の観察モードです。3Dモデルのある車（60台すべて）は
3Dでまわせます。上のバーの「🖼️ えで 見る」でイラスト版にすると、絵がベクター（SVG）なので
**どれだけ寄っても線がぼやけません**（「🧊 3Dで 見る」で戻ります。えらんだほうは端末に残ります）。

| そうさ | できること |
| --- | --- |
| ゆびでドラッグ／ピンチ | 3Dはまわす・大きくする、イラストは動かす・大きくする（マウスはドラッグとホイール） |
| 右下のバー | ＋ − スライダー ⟲（もとにもどす）。倍率も出る |
| 左のボタン（3D） | ななめ・よこ・まえ・うしろ・上から・ぐるり。▶ で にだいをかたむける・はしごをのばす など |
| ◯印 | その部分へカメラが飛び、まわりが暗くなってそこだけ光る。名前と説明が出る |
| 下のリスト | 全部の部分の一覧。押すとその部分へ飛ぶ |
| キーボード | `Esc` で閉じる（部分を選んでいるときは、まず選択を解除） |

- ◯印は `car-art.js` の `data-part`（3Dはモデルの部品）から**自動で作られます**。
- 見た部分には ✓ が付き、端末に保存されます。上のバーに「見た ぶぶん ◯こ」と出ます。
  「全部見つける」ことをゴールにはしていません。数は記録として静かに出すだけです。
- 部分のならびは、イラストは絵の左から、3Dはキーの順です。**しごとに合うつくりを先にならべる、
  といったことはしません**（それを見つけるのが子どもの学習なので）。
- この画面では `photo` を設定していても**イラストか3Dを使います**（写真では部分を光らせられないため）。

### 部分の名前と説明を足す・直す（`parts-data.js`）

```js
window.partInfo = {
  tire: {
    name: 'タイヤ',
    text: 'ゴムで できた わです。まわって 車を すすめ、……'
  }
};
```

`car-art.js` の `data-part` と同じキーにします。`name` は車のページの「ぶぶんの名まえ」と
くわしく見るの◯印に、`text` はくわしく見るの説明に出ます。**`text` はどの車にもあてはまることだけ**を書き、
その車のしごととの関係（「〜ために、〜が ついて います」）は書きません。
書き方のきまり（分かち書き・全部の漢字にルビ）は `hon-data.js` と同じで、`selftest.html` が次を自動で確かめます。

- 絵にある `data-part` が全部 `partInfo` にそろっているか
- `partInfo` に使われていないキーが残っていないか
- 説明の漢字にルビの付け忘れがないか

## じどう車を 追加・変更する

### 1. 一覧（`cars-data.js`）

```js
{
  id: 'truck',                  // 半角英字。URL（#/car/truck）になる
  name: 'トラック',              // 画面に出る名前（漢字には <ruby> を付ける）
  kana: 'トラック',              // よみ。さくいんの並びと読み上げに使う
  category: 'hakobu',           // hakobu / tsukuru / mamoru / kurashi / sodateru / basho
  art: 'truck',                 // car-art.js のキー
  photo: 'assets/truck.webp'    // 写真がなければ null（イラストを使う）
}
```

- **ならびがページばんごうになります**（`carCategories` の順 → その中は `cars-data.js` の順）。
  途中に足すと、うしろのページばんごうが全部ずれます。子どもは「28ページ」でおぼえていることがあるので、
  足すときはなるべくなかまの最後に足してください。
- ⚠️ ここに **教科書の型の文（しごと・その ために・つくり）を書かないこと。** 2026-11-08 に消したものです。

### 2. 車のページの中身（`hon-data.js`）

```js
window.honData = {
  ladder: {
    catch: '高い ところの 人を たすける、のびる はしごの 車',   // 名前の 下に 出る ひとこと
    pages: [
      { h: 'ぐんぐん のびる はしご', s: [                      // 見出しと 文
        { k: 't', part: 'ladder', t: 'はしご車の はしごは、……' }
      ] }
    ],
    kazu: [ { l: 'はしごの ながさ', v: '30〜40メートルくらい' } ],  // かずで 見る
    src:  [ { n: '○○消防局「はしご車」', u: 'https://…' } ]     // しらべた ところ（おとなの かたへ）
  }
};
```

**書くときのきまり**（`node tools/check-hon.mjs` が機械で見ます。CI でも走ります）

- **教科書の型にしない。** 「その ために」「しごとを して います」は書かない
- `k` は しごと＝`s`（2つ以上）／つくり＝`t`（5つ以上）／その他＝`o`（1つ以上）。全部で11〜18文。
  **画面には出ません**（材料が足りているかの検査だけに使う）
- 見出しは、何が書いてあるかが分かることばにする。「しごと」「つくり」ということばは使わない
- 1文だけノートに写されても意味が通るように、主語を入れる（「これは」「その」で始めない）
- 分かち書き。漢字にはすべて `<ruby>`。数字は半角の算用数字（`<ruby>4本<rt>よんほん</rt></ruby>`）
- `part` はその文がどの部分のことかの目じるし（`car-art.js` の `data-part` と同じ名前、2種類以上）。
  **画面には出しません。** 本文に出てくる部分が、ページの「ぶぶんの名まえ」の絵に必ずあることを確かめるために使います
- 事実は公式資料で確かめ、`src` に2つ以上書く。数には「やく」「くらい」を付ける。会社名・商品名・地名は書かない

### 3. イラスト（`car-art.js`）

`ART.〇〇 = { label, w, h, draw(L) }` を足します。

- 地面は `y = 200`、**1メートル ＝ 28たんい**（全車共通の縮尺）
- `w`・`h` は実際に描いた大きさ（たんい）。ここから「ながさ やく◯メートル」と、
  車のページの「1年生とくらべた大きさ」（`carArt.svg(id, 'size')`）を作ります
- 「大きさくらべ」の枠に収まるのは `w ≦ 440`（約15.7メートル）・`h ≦ 180`（約6.4メートル）まで
- `rect() / circ() / poly() / line() / path() / wheel() / glass()` などの部品ヘルパーを使います
- 名前を付けて見せたい部分には `{ part: 'nidai' }` のように `part` を渡す
  （車のページの「ぶぶんの名まえ」とくわしく見るの◯印になる。`parts-data.js` にも足す）

### 4. たしかめる

`selftest.html` をブラウザで開くと、次をまとめて確認できます。

- もくじ・さくいん・見かた・大きさくらべ・車のページが出るか。ページばんごうが どこでも同じか
- むかしのURL（`#/hon`・`#/hon/<id>`）と知らない車のURLが、正しいページへうつるか
- **全60ページに、答え・教科書の型・ペン・メモ・「しごと」「つくり」のラベルが出ていないか**
- 全60ページで、見出し・文・かずで見るがデータどおり出て、まえ・つぎのページへめくれるか
- 「ぶぶんの名まえ」が絵の部分と同じ数あり、押すと光ってふきだしが絵の中に出るか
- 読み上げテキストに漢字が残っていないか
- しおりがはさめて、もくじに集まり、保存されるか。むかしの★がしおりとして残るか
- むかしのペンの線（`jz.hon.*`）とかきうつしシート（`jz.sheet.*`）が片づくか
- 写真と出典がそろい、写真の下とおとなのかたへに出るか
- くわしく見るの◯印・説明・✓、3D ⇄ えの切りかえ（WebGL が使えるとき）
- `parts-data.js` が絵の `data-part` を全部カバーし、ルビの付け忘れがないか

`ALL PASS` と出れば大丈夫です（いま 66 checks）。
3Dモデルのほうは `selftest3d.html` が別に確かめます（大きさ、◯印、▶の動き など）。

## 3Dで まわして 見る

**収録している60台すべて**が、ブラウザの中で組み立てた3Dモデルになっています。
車のページの「🔬 くわしく 見る」で開きます。

- ◯印は車を回してもついてきて、うら側に行くと消えます
- **▶ ボタン**で、にだいがかたむく・はしごがのびる・としょかん車のかべがひらく などを実際に動かせます
- WebGLが使えない端末では、**イラスト版**が出ます（3Dは動的読みこみなので、失敗しても図鑑は動きます）
- 3D（three.js を含めて1MB余り）は、くわしく見るを開いたときにはじめて読みこみます

作りかた・じどう車の足しかた・組みこみの中身は [`README-3D.md`](README-3D.md) を見てください。
three.js を `vendor/` に同梱しているので、**ビルドは不要のまま**です。

## 写真

60台のうち **57台は本物の写真**、のこり3台（けんけつ車・キッチンカー・すいどうこうじ車）はイラストです。
写真はすべて **Wikimedia Commons の自由ライセンスの写真**（CC0・パブリックドメイン・CC BY・CC BY-SA）で、
生成AIの画像やネットの画像のスクリーンショットは使っていません。会社のロゴ・車種名・消防や警察の標章・
ナンバー・人の顔は、ぼかすか切り抜いてあります。

- 撮影者・ライセンス・元のページ・変えたところは `photo-credits.js` にあります。車のページでは
  **写真の下に撮影者とライセンス**（リンクつき）を小さく出し、ファイル名・元のページ・変えたところは
  ページのいちばん下の「おとなの かたへ」に入れています。一覧はフッターから行ける **`credits.html`**。
  ライセンスの条件なので消さないこと。
- 写真を足す・替えるときは、`assets/` に画像を置き、`cars-data.js` の `photo` にパスを書き、
  `photo-credits.js` に出典を足します。くわしくは [`assets/README.md`](assets/README.md)。
- 写真の車でも、「ぶぶんの名まえ」は写真の下のイラストで光ります（写真では部分を光らせられないため）。

## 動作について

- 読み上げは端末の音声合成（Web Speech API）を使います。日本語の音声が入っていない端末では
  音が出ないことがあります。
- しおり（`jz.stars`）、もくじで最後にえらんだしょう（`jz.filter`）、くわしく見るの ✓（`jz.kz.<id>`）と
  3D/イラストのどちらで見るか（`jz.use3d`）は、その端末の `localStorage` に保存されます。
  文字や名前などは保存しません。端末をまたいでは共有されません。
  保存が禁止されている端末では印が残らないだけで、それ以外の機能はそのまま使えます。
- 文字（BIZ UDPGothic / Kosugi Maru）はこのサイトから配っています（`fonts/`。外のサイトには読みに行きません）。

## 素材について

イラストはこのリポジトリ内で描いた SVG です。3Dモデルも、外部のモデルデータを使わず
`car3d.js` の中で箱や円柱から組み立てています（`vendor/three.module.min.js` は
three.js — MIT ライセンス）。

車のページの文（`hon-data.js`）は、教科書や市販の図鑑の文を写さず、公的な資料
（消防・警察・自治体・省庁）、メーカーの製品資料、業界団体の資料などで調べた事実から
新しく書いています。1台ずつ、書いた担当とは別の担当がウェブの出典で1文ずつ確かめ直し、
確かめられなかった文は消すか「〜ものも あります」に弱めました。出典は各ページの
「おとなの かたへ」と `hon-data.js` の `src` にあります。

### まだ のこって いる こと

- **出典のリンクは、このリポジトリの作業環境からは開けないものが多く、検索結果の要約で
  中身を確かめています。** 授業で使う前に、気になるページの「おとなの かたへ」を開いて
  確かめてください。リンク切れや内容の変わったものがあれば、その文を直します。
- すいどうこうじ車の絵と3Dは、うでの先がバケット（土をほる形）になっています。
  調べた資料では、水道工事で土をほるのは別の重機と手作業で、車のうではクレーン（荷の積みおろし）
  でした。文はクレーンの説明に直してありますが、絵はまだ直していません。
- ガスこうじ車の絵のランプは黄色（工事中の作業灯）です。ガスもれに駆けつける車は
  赤色灯とサイレンの緊急自動車なので、車のページではランプの色を書いていません。
- 新しく足した画面の字のうち、1・2年生で習わない漢字（「おとなの かたへ」の中など）は、
  配っている書体に入っていないので端末の書体で出ます。`node tools/fonts/build-fonts.mjs` で
  書体を作り直すと入ります（Google Fonts に届く環境で走らせる）。
