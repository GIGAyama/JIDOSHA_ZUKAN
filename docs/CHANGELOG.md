# 更新の記録

このアプリの変わったところです。

## 2026-11-08
- 車のページを、読んでしごととつくりを自分で見つける図鑑の作りにしました
- 教科書の型の答えが出る①②③のページをなくしました
- 文に線を引いてメモに集め、カードの型にならべるきのうをなくしました
- さくいん（あいうえお順）とページばんごうを足しました
- 「ずかんの見かた」のページを足しました
- 写真の出典やしらべた資料は、ページのいちばん下に小さくまとめました
- 「★えらんだ車」を、つけた印はそのままで「しおり」にしました
- 57台の車の絵を、出どころのはっきりした本物の写真に入れかえました
- 写真の撮影者とライセンスを、写真の下と一覧ページに出すようにしました

## 2026-11-07
- 図書室の図鑑のかわりに読める「じどう車の本」を、60台ぶん入れました
- 本の文に、しごとは青・つくりは緑の線を引いて、メモに集められるようにしました
- ①②③のページの説明と絵で、事実とちがっていたところを直しました
