# assets — 車の 写真を 置く フォルダ

このサイトの 絵は、**基本は SVGイラスト**（`car-art.js` で描いています）です。
`cars-data.js` の `photo` に パスを 書いた 車だけが、イラストの かわりに 写真に なります。

## いまの じょうたい（2026年11月）

- 全60台のうち **57台が 写真**です。のこりの 3台（`blood` けんけつ車・`kitchen` キッチンカー・
  `waterworks` すいどうこうじ車）は イラストです。
  - けんけつ車：赤十字の 標章が 写るので、写真に しません（下の「置いては いけない 画像」）
  - キッチンカー：お店の 看板を ぼかすと、横の まどと カウンターが 見えなく なるので 見送り
  - すいどうこうじ車：使える 写真が 見つからなかった
- 写真は すべて **Wikimedia Commons の 自由ライセンスの 本物の 写真**（CC0・パブリックドメイン・
  CC BY・CC BY-SA）です。生成AIの 画像は 使って いません。
- 撮影者・ライセンス・元の ページ・どこを 変えたかは **`photo-credits.js`** に あり、
  写真の 下と **`credits.html`**（写真の 出典の 一覧）に 出ます。ライセンスの 条件なので 消さないこと。
- 以前は 60台すべてに 写真を 置いていましたが、**実在の 企業ロゴ・車種名・公的機関の 標章が
  写り込んでいた**ため 2026年8月に 削除し、のこった 11台も 出どころの 記録が 無かったので、
  2026年11月に すべて 置きかえました。

## 写真の えらびかた・加工の しかた（いまの 57台は この とおりに 作った）

1. Wikimedia Commons で、ライセンスが **CC0 / Public domain / CC BY / CC BY-SA** の 写真を さがす
   （NC・ND・GFDL のみ・不明は だめ）。本物の 写真で、車ぜんたいが よこか ななめ前から 写って いる もの
2. 下の「置いては いけない 画像」に あたる ものを **ぼかすか 切りぬく**。読めたら ぼかす
3. 長辺 640px・50KB 以下の WebP に する
4. `photo-credits.js` に 出典を 足し、`cars-data.js` の `photo` に パスを 書く
5. `selftest.html` が、出典が そろって いるか・ライセンスが きまりの 中か・画像が 読めるかを 確かめる

CC BY-SA の 写真を 加工した 画像は、元と おなじ CC BY-SA で 公開して いる あつかいです
（LICENSE の 但し書きの とおり、ソースコードの MIT は ここには かかりません）。

## 手順

1. 画像をこのフォルダに置く（ファイル名は `cars-data.js` の `id` に合わせると分かりやすい）

   ```
   assets/truck.webp
   assets/crane.webp
   ```

2. `cars-data.js` の その車の `photo` に、パスを書く

   ```js
   { id: 'truck', … , photo: 'assets/truck.webp', … }
   ```

3. これで その車だけ 写真になります。`photo: null` のままの車はイラストのままです。
   1台ずつ差しかえられるので、写真が用意できたものから順に置きかえていけます。

## 画像の めやす

| 項目 | おすすめ |
| --- | --- |
| 形式 | `.webp`（`.jpg` `.png` でも動きます） |
| 大きさ | **長辺 640px**（画面ではカードが 240px、車のページでも 500px ほどなので、これで足ります） |
| 重さ | **1枚 50KB 以下**。いま入っている11枚は平均24KBです |
| 向き | **横向き（車の側面）** がそろっていると、一覧で見くらべやすくなります |
| 背景 | 白や単色だと、まわりのカードとなじみます |

> 大きすぎる画像は入れないでください。以前は 1024px・1枚527KB の画像が入っていて、
> 一覧を最後までスクロールすると **28MB** 読み込んでいました。
> 長辺640pxのWebPに変えてあります。学校のWi-Fiでクラス全員が
> 一斉に開く場面では、ここが体感を決めます。

画像は はみ出さずに全体が入るように表示されます（`object-fit: contain`）。

## ⚠️ 置いては いけない 画像

- **実在の 企業ロゴ・企業名・車種名（型式名）が 写り込んだ 画像は 置かないでください。**
  車体に書かれた社名、建設機械のメーカー名・型番、車のエンブレムなどが これに あたります。
- **公的機関の 標章（警察章・消防章、自治体や 官庁の 紋章、学校名 など）が
  写り込んだ 画像も 置かないでください。**
- **とくに 赤十字標章（白地に赤い十字）は、「赤十字の標章及び名称等の使用の制限に関する法律」で
  使用が 制限されており、罰則も あります。** 献血バスや 救護車の 写真は、
  たとえ 資料用でも このリポジトリには 置かないでください。同じ理由で、
  赤新月・レッドクリスタルの 標章も 使えません。
- 「写り込みだから 大丈夫」と 自己判断せず、**マークが 見えるなら ぼかすか 切りぬいてから** 置いてください。
  外しきれない ときは 置かない。イラスト（`car-art.js`）で 十分に 学習できます。

## そのほか 気をつけること

- 部位ハイライト（「つくり」の文を押すと絵の一部が光る機能）は、**写真の車でも使えます**。
  写真のうしろにイラストを持たせてあり、文を押したあいだだけイラストに入れかわって光ります。
  もう一度押すと写真にもどります。
- インターネットで見つけた写真には著作権があります。**検索結果の 画像や スクリーンショットは 使えません。**
  利用条件（ライセンス）が はっきりした 写真か、自分で撮った写真を 使ってください。
- 人の顔が写っている写真は、公開してよいか確認してから置いてください。
- ナンバープレートの 番号が 読める 写真も 避けてください。
