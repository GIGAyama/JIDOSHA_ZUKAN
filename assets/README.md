# assets — 写真に 差しかえるための フォルダ

このサイトは、はじめは **SVGイラスト**（`car-art.js` で描いています）を表示します。
実物の写真を使いたいときだけ、ここに画像を置いてください。

## 手順

1. 画像をこのフォルダに置く（ファイル名は `cars-data.js` の `id` に合わせると分かりやすい）

   ```
   assets/truck.webp
   assets/crane.webp
   ```

2. `cars-data.js` の その車の `photo` に、パスを書く

   ```js
   { id: 'truck', … , photo: 'assets/truck.webp', … }
   ```

3. これで その車だけ 写真になります。`photo: null` のままの車はイラストのままです。
   1台ずつ差しかえられるので、写真が用意できたものから順に置きかえていけます。

## 画像の めやす

| 項目 | おすすめ |
| --- | --- |
| 形式 | `.webp`（`.jpg` `.png` でも動きます） |
| 大きさ | **長辺 640px**（画面ではカードが 240px、詳細ページでも 340px なので、これで足ります） |
| 重さ | **1枚 50KB 以下**。いま入っている52枚は平均29KBです |
| 向き | **横向き（車の側面）** がそろっていると、一覧で見くらべやすくなります |
| 背景 | 白や単色だと、まわりのカードとなじみます |

> 大きすぎる画像は入れないでください。以前は 1024px・1枚527KB の画像が52枚入っていて、
> 一覧を最後までスクロールすると **28MB** 読み込んでいました。
> 長辺640pxのWebPに変えて **1.5MB** になっています。学校のWi-Fiでクラス全員が
> 一斉に開く場面では、ここが体感を決めます。

画像は はみ出さずに全体が入るように表示されます（`object-fit: contain`）。

## 気をつけること

- 部位ハイライト（「つくり」の文を押すと絵の一部が光る機能）は、**写真の車でも使えます**。
  写真のうしろにイラストを持たせてあり、文を押したあいだだけイラストに入れかわって光ります。
  もう一度押すと写真にもどります。
- インターネットで見つけた写真には著作権があります。使う前にかならず利用条件を確かめてください。
  自分で撮った写真や、学校で撮影した写真がいちばん安心です。
- 人の顔が写っている写真は、公開してよいか確認してから置いてください。
